# Fish Pet Game

A simple virtual pet fish game that runs in the terminal, created with C# and .NET.

## Current Features

- Displays an ASCII fish that swims across the screen
- Basic game loop

## How to Run

```
dotnet run --project FishGame.Api
dotnet run --project FishGame.Console
```

## Swagger

`http://localhost:5002/swagger`

## Local db

`/fish/FishGame.Api/Data/fishgame.db`

## Future Features

- Fish stats (hunger, happiness, etc.)
- Feeding mechanics
- Growth and evolution
- Day/night cycle
- More complex fish behaviors
